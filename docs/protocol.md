# PocketClaw Wire Protocol v0

This document is the human-readable companion to the zod schemas in
`packages/shared` (`@pocketclaw/shared`), which are the **single source of truth**.
If this document and the schemas ever disagree, the schemas win — and please open a PR.

## Transport

| Channel | Endpoint | Auth |
|---|---|---|
| WebSocket | `ws://<host>:8787/ws?token=<token>` | token query param |
| REST | `http://<host>:8787/api/*` | `Authorization: Bearer <token>` header |

The token is the bearer token from `~/.pocketclaw/config.json`, generated by
`pocketclaw init`. The host is expected to be reachable only inside a private
network (Tailscale tailnet or LAN) — see [security.md](./security.md).

All WebSocket messages are JSON objects with a `"type"` field.

## REST endpoints

REST exists for the Live Activity App Intents (which cannot hold a WS connection)
and for simple polls.

### `GET /api/sessions`

```json
{ "sessions": [ /* SessionSummary[] */ ] }
```

### `POST /api/decision`

Used by the Live Activity Approve/Deny App Intent. The host enforces risk tiers
server-side: a `high`-risk request can never be approved through this endpoint
from a Live Activity flow (the widget never offers the button, and the host is
the final authority).

Request body:

```json
{ "requestId": "req_8f3a", "behavior": "allow" }
```

`behavior` is `"allow"` or `"deny"`. Response:

```json
{ "ok": true }
```

### `GET /api/obsidian/today`

```json
{ "path": "PocketClaw/Daily/2026-06-11.md", "markdown": "# 2026-06-11\n..." }
```

### `GET /api/health`

```json
{ "ok": true, "version": "0.1.0" }
```

## WebSocket messages: Client → Host

### `hello`

Sent immediately after connect. Identifies the client (stable per-install id).

```json
{ "type": "hello", "clientId": "iphone-a1b2c3" }
```

### `spawn`

Start a new Claude Code session. `workspace` is either a registered alias
(string) or an explicit path (object).

```json
{ "type": "spawn", "workspace": "blog", "prompt": "fix the RSS feed" }
```

```json
{ "type": "spawn", "workspace": { "path": "/Users/me/code/blog" } }
```

`prompt` is optional; without it the session starts idle in `waiting_input`.

### `input`

Send user text to a running session.

```json
{ "type": "input", "sessionId": "sess_42", "text": "use pnpm, not npm" }
```

### `decision`

Resolve a permission request (same semantics as `POST /api/decision`, plus an
optional note that is recorded in the audit log).

```json
{ "type": "decision", "requestId": "req_8f3a", "behavior": "deny", "note": "wrong branch" }
```

### `kill`

```json
{ "type": "kill", "sessionId": "sess_42" }
```

### Workspace management

```json
{ "type": "list_workspaces" }
```

```json
{ "type": "add_workspace", "alias": "thesis", "path": "/Users/me/Documents/thesis" }
```

```json
{ "type": "remove_workspace", "alias": "thesis" }
```

### `overseer_ask`

Ask the Overseer meta-session a question about all running sessions.

```json
{ "type": "overseer_ask", "question": "which session is closest to done?" }
```

## WebSocket messages: Host → Client

### `sessions`

Full session list. Sent on connect and on **any** change (status, lastMessage,
todo, cost). Clients should treat it as a full replacement snapshot.

```json
{
  "type": "sessions",
  "sessions": [
    {
      "id": "sess_42",
      "title": "fix the RSS feed",
      "workspace": { "alias": "blog", "path": "/Users/me/code/blog", "lastUsedAt": 1781136000000 },
      "status": "waiting_permission",
      "lastMessage": "I need to edit feed.ts",
      "startedAt": 1781135000000,
      "updatedAt": 1781136200000,
      "todo": { "done": 2, "total": 5 },
      "costUsd": 0.41
    }
  ]
}
```

### `workspaces`

```json
{
  "type": "workspaces",
  "workspaces": [
    { "alias": "blog", "path": "/Users/me/code/blog", "lastUsedAt": 1781136000000 }
  ]
}
```

### `event`

A session transcript event. See [SessionEvent](#sessionevent) below.

```json
{
  "type": "event",
  "sessionId": "sess_42",
  "event": { "kind": "assistant_text", "text": "Found the bug in feed.ts line 12." }
}
```

### `permission_request`

```json
{
  "type": "permission_request",
  "request": {
    "requestId": "req_8f3a",
    "sessionId": "sess_42",
    "sessionTitle": "fix the RSS feed",
    "tool": "Edit",
    "inputPreview": "feed.ts: replace pubDate format",
    "riskTier": "medium",
    "createdAt": 1781136200000
  }
}
```

### `permission_resolved`

Broadcast when a request is resolved by **any** client or by the host's
default-deny timeout — so every connected UI can dismiss it. (Low-tier
auto-allows never surface a request, so they never produce this message.)

```json
{ "type": "permission_resolved", "requestId": "req_8f3a", "behavior": "allow" }
```

### `overseer_answer`

```json
{
  "type": "overseer_answer",
  "question": "which session is closest to done?",
  "answer": "sess_42 (blog) — 4/5 todos done, currently writing tests."
}
```

### `error`

```json
{ "type": "error", "message": "unknown workspace alias: blgo" }
```

## Types

All timestamps are Unix epoch **milliseconds**.

### Workspace

```ts
{ alias: string, path: string, lastUsedAt?: number }
```

### SessionStatus

```ts
"starting" | "running" | "waiting_input" | "waiting_permission" | "done" | "error"
```

### SessionSummary

```ts
{
  id: string,
  title: string,
  workspace: Workspace,
  status: SessionStatus,
  lastMessage: string,
  startedAt: number,
  updatedAt: number,
  todo?: { done: number, total: number },
  costUsd?: number
}
```

### RiskTier

```ts
"low" | "medium" | "high"
```

### PermissionRequest

```ts
{
  requestId: string,
  sessionId: string,
  sessionTitle: string,
  tool: string,
  inputPreview: string,
  riskTier: RiskTier,
  createdAt: number
}
```

### SessionEvent

A tagged union on `kind`:

```ts
  { kind: "assistant_text", text: string }
| { kind: "tool_use",    tool: string, inputPreview: string }
| { kind: "tool_result", tool: string, ok: boolean, preview: string }
| { kind: "status",      status: SessionStatus }
```

## Risk tiers

Computed host-side in `packages/shared/src/risk.ts`:

| Tier | Rule | Behavior |
|---|---|---|
| `low` | tool ∈ { Read, Grep, Glob, WebSearch, TodoWrite, Task, NotebookRead } | auto-allow silently, but log to audit |
| `high` | Bash whose command matches `/(rm\s+-rf\|sudo\|git\s+push\s+--force\|--force\|mkfs\|shutdown\|reboot\|deploy\|publish\|>(\s*)\/dev)/i`, **plus** any tool name matching `/delete\|remove/i` | requires decision; Live Activity must **not** offer Approve — only "Open app" |
| `medium` | everything else (Edit, Write, non-dangerous Bash, WebFetch, `mcp__*`) | requires decision; approvable from Live Activity |

## Versioning

This is **v0**: breaking changes may occur without negotiation. Clients should
check `GET /api/health` `version` and refuse to operate on an unknown major.
